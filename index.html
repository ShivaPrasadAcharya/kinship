How to use Kinship

1. Build a family. Add a root person, then add children, parents, siblings, or spouses. Select a name or use its Edit / Delete buttons, including for saved and imported records. Names, relationships, birth order, dates, and comments remain editable. People with the same name are supported.

2. Make it yours. Family settings changes the table name and description. Customize changes the title, column labels, fonts, colors, numbering, and diagram layout. Table and Diagram use the same data.

Search. The search ribbon stays at the top while scrolling. Search one family or choose All families / tables, open Filters for field, match mode, gender and status, and use ↑ / ↓ or Enter / Shift + Enter to visit matched people. Nepali normalization and space-agnostic matching are enabled by default. Highlight and Only matches can be toggled independently. Each family in the All view has its own JSON export.

3. Publish a family. Select a family and export its JSON (one family per file), choose Add .json files, upload it into the repository’s data/ folder, then commit. GitHub Actions validates all JSON files, discovers every family, and deploys the site. No index editing is needed.

Local edits and published data. Browser edits save automatically on this device. Export before moving to another device. Uploading the export to GitHub publishes it. For an existing published family, the export keeps its original filename: replace that file in the same folder to publish edits or deletions. Restore published version discards this family’s local edits. Page customization is saved locally and in exports; a single site-settings.json in the repository root sets shared defaults.

Read the family. Numbered badges show the generation (1, 2, 3…), with deeper indentation for later generations. Siblings with the same parents stay together, ordered by saved birth order, then comparable birth dates; otherwise their existing order is retained. Henry numbers remain separate. In the chart, each parent has a distinct connector style, repeated on their card and in the expandable Parent connector key. Two spouses flank their partner in the top-to-bottom layout.

Henry numbers. Children follow the first parent listed in their record. Other parents and spouses remain connected in the diagram. Child order is used when given; otherwise added order is used. Multiple roots get a bracketed prefix. Spouses without a descendant line have no Henry number. Numbers 10–36 use X and A–Z; larger child numbers are bracketed.

Existing files. The original Henry Number Generator’s tables / entries JSON is supported, along with the new editable tables / people format. Unresolved legacy relationships are reported for correction. Dates accept your preferred calendar and format.
